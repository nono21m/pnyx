# Pnyx — De la Pnyx au pixel

Application web (PWA) : l'évolution historique des sociétés, d'Athènes à aujourd'hui. Carte interactive, frise, thèmes parents et contradictoires, quiz, synthèse.

- Installer sur iPhone : ouvrir le lien dans Safari ou Chrome → Partager → Sur l'écran d'accueil.
- Hors ligne après une première ouverture connectée.
- Mise à jour : modifier les fichiers, puis changer `V` dans `sw.js` (ex. `pnyx-v1-2`), sinon l'iPhone garde l'ancienne version.
- Contenu rédigé avec une IA (v1-1) : à vérifier avant tout usage pédagogique. Carte : Natural Earth (domaine public) via world-atlas.
